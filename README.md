A Notepad-style text editor that runs in one HTML file, with no install or dependencies. Notes autosave in your browser.

Features

Multiple tabs, which you can rename or duplicate
Find and replace, go to line, and line shortcuts (duplicate, delete, move)
Auto-correct for common typos, and optional spell check underlines
Fix spelling and grammar with Claude, when it’s available
Markdown preview, with auto-continuing lists
Text tools: change case, sort lines, remove duplicates, make bullet, numbered or checklist lines
Choose your font, size, text colour and background colour
Save as .txt or .md, and back up or restore all tabs as .json
Light and dark mode, zoom, line numbers, and read-only mode
